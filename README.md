# Sistema de Gestión de Dispositivos de Cómputo

## Descripción del proyecto

Este proyecto propone desarrollar un sistema para registrar y controlar los dispositivos de cómputo de una institución educativa o empresa. El sistema permitirá consultar información de los equipos, conocer su estado y llevar un registro de su mantenimiento.

## Problema

El control manual de los dispositivos puede provocar pérdida de información, dificultades para localizar equipos y falta de seguimiento de los mantenimientos.

## Hipótesis

Si se implementa un sistema de gestión de dispositivos de cómputo, entonces se mejorará el control de los equipos, se reducirá el tiempo necesario para consultar su información y se facilitará el seguimiento de sus mantenimientos.

## Objetivo general

Desarrollar una propuesta de sistema que permita organizar la información de los dispositivos de cómputo y facilitar su administración.

## Beneficios esperados

- Mejor organización de los dispositivos.
- Consulta rápida de la información de cada equipo.
- Mejor seguimiento de los mantenimientos.
- Reducción de errores en los registros manuales.
